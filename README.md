Q1 How did you approach creating more flexible functions with parameters?

I started by identifying the values that might change each time the function was called. Instead of writing separate functions for each value, I used parameters so the same function could work with different inputs. This made my functions more reusable and helped me understand how arguments are passed into a function.

Q2 What challenges did you face while incorporating conditional logic in your functions?

One challenge I faced was incorporating conditional logic and making sure all possible cases were handled. For example, while testing my function, I found that there were many negative testing cases that I needed to consider, such as invalid, negative, or unexpected inputs. Testing all these cases took some time. I solved this by breaking the conditions into smaller steps and testing different inputs one at a time. This helped me understand how each condition affected the output and made my function more reliable. 

Q3 How does refactoring improve the readability and maintainability of your code?

Refactoring helped me make my functions simpler and easier to follow. For example, while working on the lab, I noticed that some of my code was repeated and could be organized better. I changed it so that the same logic could be handled by a function instead of writing the same code again. This made the code easier to read and also made it easier to make changes or fix errors later without changing the same code in multiple places.
